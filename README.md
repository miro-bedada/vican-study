# vican-study
R analysis of physical quality of life among cancer survivors

**Project overview**

This project uses R to analyze the VICAN survey dataset and explore factors associated with the physical quality of life of cancer survivors.

**Methods**

Data inspection and missing-value assessment

Recoding categorical variables

Descriptive statistics

Visualization of age and quality-of-life distributions

Univariable analyses

Multivariable linear regression

Regression diagnostic plots
